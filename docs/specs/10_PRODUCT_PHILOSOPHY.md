# Logan Product Philosophy

## Purpose

Logan is a personalized intelligence platform---not a feed, chatbot,
screener, or dashboard.

## Core Principles

-   Intelligence before information.
-   Reasoning before presentation.
-   Explain every conclusion.
-   Separate Hit Quality from User Value.
-   Personalize without manipulating.
-   Preserve user trust over engagement.
-   Track opportunities over time.
-   Memory is earned through evidence and outcomes.

## UX Philosophy

The Opportunity Field is the primary experience. Users should understand
within 30 seconds: 1. Logan knows what matters. 2. Logan explains why.
3. Logan continuously learns.

## Visual Philosophy

-   Calm, premium, modern.
-   Motion communicates state.
-   Center = Logan Intelligence.
-   Distance = importance.
-   Brightness = lifecycle.
-   Pulse = Action Window.
